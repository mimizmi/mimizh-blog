
## 遍历

以二叉树根节点遍历的次序，可以分为三种遍历：根节点在左子树和右子树之前，称为先序遍历(preorder), 根节点在左右子树之间，称为中序遍历(inorder)，根节点在左右子树之后，称为后序遍历(postorder)

遍历的手段可以很自然的想到使用递归实现
```c++

void preorder(TreeNode* root){
	...
	printf(root->val);
	preorder(root->left);
	preorder(root->right);
	...
}

void inorder(TreeNode* root){
	...
	inorder(root->left);
	printf(root->val);
	inorder(root->right);
	...
}

void postorder(TreeNode* root){
	...
	postorder(root->left);
	postorder(root->right);
	printf(root->val);
	...
}
```

但是有时候我们也会希望不使用递归的形式，毕竟函数递归本身是有代价的。

主流解法分为两类，以中序遍历为示例

* 使用栈作为辅助结构
	```c++
	cur = root;
	while(cur != nullptr || !st.empty()){
		//思路同理，先遍历到最左叶子节点，将节点信息推入栈以便后续回溯
		while(cur->left != nullptr){
			st.push(cur);
			cur = cur->left;
		}
		cur = st.top();
		st.pop();
		printf(cur->val);
		cur = cur->right;
	}
	```
* 不使用栈作为辅助结构(Morris中序遍历)
	```c++
	// Morris的思路很巧妙，但是一样有迹可循。
	// 出于优化栈结构的空间，我们可以利用叶子节点左右子节点为空的特性。
	// 将回溯信息存储在叶子节点的右子树节点，以实现类似环状回溯的效果。
	// 简单来说，若某根节点存在左子树，该根节点的左子树中的最右子节点的右节点应指向该根节点
	// 也可以称之为根节点的前驱
	// 由此做到回跳的效果，代价是所有左子树将遍历两遍，以确保最后树结构能够还原。
	// 但很显然这样的代价是值得的
	cur = root;
	mostRight = nullptr;
	while(cur != nullptr){
		if (cur -> left == nullptr){ //到达最左直接输出
			printf(cur->val);
			cur = cur->right;
		}
		else{
			mostRight = cur->left;
			// 注意可能是第二次遍历，此时已经成环，避免死循环
			while(mostRight->right != nullptr && mostRight->right != cur)
				mostRight = mostRight->right;
			if (mostRight == cur->right){
				//还原
				mostRight->right = nullptr;
				//第二次到达说明左子树已经遍历完成，根节点需要输出
				printf(cur->val);
				cur = cur->right;
			}else{
				//否则建立回溯前驱关系，并继续遍历左子树
				mostRight->right = cur;
				cur = cur->left;
			}
		}
	}
	```
